# ClaudeUsageWidget

Claude Code のレートリミット（5時間 / 7日間 / モデル別の週次上限）を
Mac のメニューバーとオーバーレイウィジェットに表示する常駐アプリ。

## 表示

- **メニューバー**: `5h 42%  7d 40%  fable 69%` を常時表示。ホバーでリセット時刻のツールチップ。
- **ウィジェット**: 画面上部にバーをオーバーレイ表示（半透明・全Space表示・ドラッグで移動可、位置は記憶される）。

段数はリミットの数に合わせて増減する。5h / 7d の 2 段に加えて、
プランに付いているモデル別の週次上限（`fable`、`opus` など）が 1 段ずつ増える。
上限はプランによって出たり消えたりするので、キャッシュの `limits` 配列に
あるものをそのまま並べる。リサイズしても**上端の位置は動かない**。

### 色

使用率の色は API 自身の判定（`severity`）に従う。`normal` は緑、`warning` は黄、`critical` は赤。
`severity` が無い古い形式のキャッシュでは使用率で判定する（70%以上で黄、90%以上で赤）。
statusline (`~/.claude/statusline-command.sh`) と同じ規則なので、両者の色は必ず一致する。

メニューバーの数字だけは `normal` のあいだ通常の文字色にしておく。
常に緑で光っていると、ただの飾りとして目に入らなくなるため。

### キャッシュが古いとき

キャッシュの取得時刻が 15 分以上前になると、メニューバーに `⚠`、
ウィジェット下部に `〇分前のデータ` が出る。取得スクリプトが止まったまま
自信ありげな古い数字を出し続けるのを防ぐため。

## 操作

- メニューバー項目を**左クリック** → ウィジェットの表示/非表示をトグル
- **右クリック**（または ⌃クリック）→ 詳細メニュー
  - 使用率・リセット時刻・リセットまでの残り時間
  - ウィジェット表示切り替え / キャッシュ再読込
  - ログイン時に自動起動（トグル）
  - 終了

## 通知

各リミットのリセット時刻にタイマーで macOS の通知を送る。
初回起動時に通知の許可ダイアログが出るので許可すること。同じリセットに対して重複通知はしない。

モデル別の週次上限は 7 日間の枠と同時にリセットされることが多いので、
リセット時刻が同じものはまとめて 1 通にする（`7d / fable のリミットがリセットされました`）。
すでに過ぎたリセット時刻については通知しない。キャッシュが遅れていただけで、
いま知らせても意味がないため。

## データソースとトークン管理

このアプリは Keychain にアクセスしない。`~/.cache/claude-usage-cache.json`
に保存済みの使用量キャッシュだけを読む。Claude Code の statusline
(`~/.claude/statusline-command.sh`) も同じキャッシュを読み取るだけで、Keychain/API には触れない。

1. `~/.cache/claude-usage-cache.json` に `cached_at` 付きの使用量 JSON を保存しておく
2. statusline は Claude Code の表示更新時にこの JSON を読み取る
3. アプリは 60 秒ごと、またはメニューの「キャッシュを再読込」でこの JSON を読み直す

API アクセス、OAuth トークン取得、トークン更新はアプリ側でも statusline 側でも行わない。
キャッシュが古い場合でも、最後に保存された値を表示し続ける。

## ビルド & インストール

```sh
./build.sh        # swiftc でビルド → ~/Applications/ClaudeUsageWidget.app に配置
open ~/Applications/ClaudeUsageWidget.app
```

依存は Xcode Command Line Tools の swiftc のみ。
